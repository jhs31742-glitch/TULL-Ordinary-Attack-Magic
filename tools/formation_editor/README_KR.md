# TULL Formation Editor 1.0 — 사용·개발 설명서

**index.html을 데스크톱 브라우저로 여세요.** engine.js·presets.js·app.js를 같은 폴더에 둡니다. 설치·Skyrim·NIF 도구·인터넷 없이 실행합니다. 상단 English/한국어 선택으로 UI 언어를 바꿉니다. 프로그램과 설명서를 두 언어로 제공합니다.

## 프리셋 세트 → 마법 → 시전 변형 → 에셋
이름을 붙인 세트 하나에 여러 마법을 추가합니다. 마법마다 캐릭터·적·월드 중심과 독립적인 시전 변형을 갖습니다. 마법 추가·명명·복제·삭제, 시전 변형 복제·명명·삭제가 가능합니다. 단독 왼손/오른손, 양손, 공중 상태 등을 다른 변형으로 만드세요. 각 변형의 마법진·예제 마법검·표식은 추가·복제·삭제할 수 있습니다. 편집기의 개수 변경이 설치된 모드의 실제 공격 횟수나 Native 제한을 변경하지는 않습니다.

세트 이름을 입력하고 **이름으로 세트 저장**을 누르면 브라우저에 여러 세트를 보관합니다. 같은 이름은 그 항목을 덮어씁니다. **세트 JSON 내보내기**는 전체 마법·시전 변형·손별 소속·그룹·위치·각도·배율을 포함하는 휴대용 백업입니다. 브라우저 저장은 기기·브라우저·파일 경로에 의존하며 삭제될 수 있으므로 JSON도 보관하세요. 불러오기는 현재 작업을 교체하지만 실행 취소할 수 있습니다. 다른 AI나 모드 도구가 읽도록 소스를 축약하지 않고 스키마 버전을 명시했습니다.

## 선택·그룹 이동·크기·각도
중심점 클릭 또는 목록으로 선택합니다. Ctrl 클릭은 개별 추가·해제, 빈 곳 드래그는 사각형 다중 선택, Shift는 추가 선택입니다. 선택한 중심을 드래그하면 모두 함께 이동합니다. 정면 X/Z, 측면 Y/Z, 위·사선 X/Y 평면입니다. 5유닛 맞춤을 끄면 자유 이동합니다. 겹친 태양 레이어는 목록이나 **같은 그룹 선택**으로 묶으세요.

XYZ 좌표·회전 입력은 선택한 에셋 모두에 같은 변화량을 적용합니다. 각도 변경은 각 에셋 중심에서 회전하며 그룹 위치 전체를 공전시키지는 않습니다. 기본 법선으로 평면 방향을 잡은 뒤 로컬 XYZ 회전각(도)을 적용합니다. 배율 입력은 동일한 절대 배율로 맞추고, **선택 크기 배율 ×**는 기존 배율을 함께 곱하여 태양 레이어의 상대 크기를 보존합니다. 원본 반경·검/상자 XYZ 크기는 배율 적용 전 에셋 크기입니다. 모델 경로는 제작용 기록이며 실제 NIF를 읽지는 않습니다. 미리보기는 도식입니다.

실행 취소·다시 실행은 세트·마법·변형·개수·배치를 포함합니다. 텍스트 입력 중이 아닐 때 Ctrl-Z/Ctrl-Shift-Z와 Delete도 쓸 수 있습니다. 화면 맞춤은 편집기 카메라만 변경합니다.

## 좌표를 다른 모드에 적용하는 법
1. X는 캐릭터 오른쪽, Y는 앞, Z는 위입니다. 좌표는 Skyrim 게임 유닛, 입력 각도는 도 단위입니다. 미터·라디안으로 임의 해석하지 마세요.
2. 좌표 중심에는 월드 위치·방향각·기준 키·발/바운드 중심 선택·추가 오프셋이 있습니다. 편집기의 중심은 키/2 근사값입니다. 실제 적에게는 엔진의 유효한 bounds.center를 사용하세요.
3. 로컬 → 월드 = 중심 + 방향 기저×로컬 좌표. Skyrim yaw는 월드X=cos(yaw)×x+sin(yaw)×y, 월드Y=−sin(yaw)×x+cos(yaw)×y입니다. 단위 변환은 어댑터 경계에서 한 번만 합니다.
4. 마법진 법선은 로컬 +Y입니다. 회전은 BaseNormalFrame × Rz × Ry × Rx이며 Rx부터 적용합니다. 중심 변경은 위치와 법선뿐 아니라 전체 방향·롤을 보존해야 합니다. engine.js와 회귀 테스트가 이를 구현합니다.
5. 캐릭터·적 중심 배치는 해당 중심의 이동·회전을 따릅니다. **월드 좌표로 고정**하면 현재 위치와 방향을 굳혀 이후 적 이동에도 따라가지 않습니다. 실제 전역 좌표용 월드 중심은 기본 원점·방향각0으로 유지하세요.
6. 실제 렌더링 부모에 넣을 때는 부모의 월드 역변환을 적용합니다. 위치=parent.rotate.transpose×(원하는월드위치−parent.translate)/parent.scale, 회전=parent.rotate.transpose×원하는월드회전, 크기=원하는크기/parent.scale입니다. 잘못된 부모 배율은 거부하고 실제3D·포즈 노드 준비 이후 적용하세요.
7. 요청 객체·세대·소유권·수명과 취소/로드/셀 이동/사망 정리는 별도 런타임 책임입니다. 조준점이 캐릭터 중심 배치를 끌어가게 하지 마세요. 시각 발사점·피해 판정 시작점은 의도적으로 연결해야 합니다.

## 이 모드의 실제 좌표와 공중 배치
presets/toam-reviewed.json에 태양 완충, 마법사8티어, 세계/은둔자 지상 돔, 세계 공중 전방위, 심판/절제 적 중심 참조, 황제·전차·힘 손별 배치와 등 뒤 검 예제를 넣었습니다. 양손 보조 좌표는 실제 수동 편집값이며 단순 좌우 대칭 복제가 아닙니다. 공중 세계는 원본 AirWorldNormal의 아래 반구와 발 아래까지 내려가는 지점을 포함합니다.

reference/의 현재 좌표 스냅샷·직접 편집했던 JSON·source-parameters.json을 함께 보관하세요. 소스 해시와 실제 배율·반경 공식이 있습니다. 과거 원본 편집기는 전체 모드 소스 tools/layout_editor에 그대로 남습니다. 독립 개선본에는 게임 메시·텍스처·모션이나 외부 참고사진을 넣지 않았습니다.

적 중심 예제의128유닛 반경은 절제 참조입니다. 심판은 실제 적의 initialBounds.radius×profile.radiusScale로 반경과 표시 크기를 정하므로 모든 적에게128을 강제하지 마세요. 법선9개는 실제 소스값입니다. 세계의 게임 내4/8/12 계약과 범용 편집기의 자유로운 개수 설정도 구분해야 합니다. 태양 완충 간격7과 충전 중22→7은 별개이며 저장값은 한 시점의 설계 스냅샷입니다.

## 다른 AI·개발자를 위한 연동 주의
SCHEMA.md, engine.js와 tests를 먼저 읽으세요. 실제 손·주문·시전 문맥에 맞는 변형 하나를 고릅니다. 단독과 양손 배열을 동시에 합치거나 에셋 개수를 자원·피해 횟수로 오인하지 마세요. hand=left/right/shared는 명시적인 소속입니다. ID는 변형 안에서 유일하며 그룹명은 제작 편의용입니다.

“평타 때 등 뒤 소환검 생성, 강타 때 적에게 발사”는 actor 중심 follow 배치를 만든 뒤 실제 근접 이벤트에서 유효 타격을 선별하고, 강타 순간 월드 포즈와 살아 있는 적의 목표점을 스냅샷해 발사하는 방식으로 연결할 수 있습니다. 입력/타격 필터·투사체·피해·자원·수명 정리는 해당 모드에서 별도로 구현해야 합니다. 이 예제는 TOAM에 구현된 게임플레이 기능이 아닙니다.

이 편집기에서 좌표가 보인다는 사실은 게임 런타임 PASS가 아닙니다. 실제 에셋의 축·바운드·배율, 엔진 생성·첫 포즈·가시성·해제를 검증하세요. 원본 해시와 가정을 함께 남기면 다른 AI가 기존 실수를 재현하지 않고 이어갈 수 있습니다.

테스트: node tests/engine.test.cjs. 설계와 수동 좌표는 TULL, 구현·테스트·문서에는 OpenAI Codex 지원이 사용됐습니다. 독립 도구의 최종 공개 라이선스는 발행자가 정하며, 다른 게임/모드 아트의 권리는 이 도구로 이전되지 않습니다.

기본 화면은 마우스 이동과 위치·회전·크기 슬라이더를 사용합니다. 정확한 숫자 좌표·법선·원본 반경과 크기는 **상세 숫자 입력**에 접혀 있습니다. 정밀 작업 때만 펼치세요. 슬라이더 드래그 한 번은 실행 취소 한 단계이며 JSON의 같은 값을 변경합니다.

## 다른 AI용 좌표 참고 JSON
`examples/ai-coordinate-examples.json`은 정면·90도 yaw 검산·대상 고정·등 뒤 검/손 구분의 간결한 예제로 편집기에서 직접 불러올 수 있습니다. `examples/ai-reference-guide.json`은 기계가 읽는 설명서이며 편집기 불러오기 대상이 아닙니다. 실사용 TOAM 값은 `presets/toam-reviewed.json`을 사용하고 출처 해시·미리보기 가정을 확인합니다.
